# Artwork production record

Tool: built-in `image_gen`; project artwork created 2026-10-15. Selected outputs were copied into the repository as optimized WebP assets. Originals remain in the generation tool's output directory; the application depends only on repository assets.

## Character — selected hero prompt

> Use case: stylized-concept. Create a premium original brand character named Melissa for a sophisticated, welcoming English-learning studio for adults. A single iconic sculptural honeybee-inspired companion, not a literal insect and not an owl. Soft warm golden-ochre egg-shaped head merging into a small rounded honey-colored body, two tiny curved dark antennae, two large glossy inky navy oval eyes with subtle tiny highlights and raised eyebrow gesture, a gentle asymmetric confident smile. Small articulated hand-like arms and two short feet. Four cream folded-petal wings behind the shoulders arranged so their silhouette quietly suggests an open book or letter M, elegantly layered with subtle paper veins. A deep ink-navy knitted short scarf with one small periwinkle stitch. Tactile high-end stop-motion ceramic and soft flocked felt mixed media, visibly refined organic imperfections, exquisite studio lighting and soft warm shadows, like a collectable art toy photographed for an independent design magazine. Whole body fully in frame, three-quarter front pose, one hand lifted in a small welcoming wave, other hand holding a tiny closed cream notebook. Calm intelligent approachable expression. Centered composition with generous clear space. Transparent background, actual alpha. Colors: honey #eeb94f, cream #f6f3e9, inky blue #192b3a, one tiny muted periwinkle accent. No lettering or watermark.

A subsequent edge-cleanup generation was reviewed and not selected because it did not improve the full-body image. The selected original was checked against the actual warm-paper application background at its displayed size. The portrait and identity board use opaque paper backgrounds.
