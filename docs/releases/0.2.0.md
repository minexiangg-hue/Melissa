# Melissa 0.2.0 — English, in good company

Released 2026-10-15. Preview: **https://hermoscare.com/melissa**.

This edition turns the scripted foundation into a working AI learning studio. The existing project directory, guest identity and learner data are preserved.

The external API adapter is implemented and exercised against real HTTP fixtures. No external API credential was available for a billable upstream smoke test; the deployed preview uses authenticated Codex. Set the documented LLM configuration to switch adapters.

## Production acceptance

The isolated production build completed an actual browser flow with a past-tense correction, a new workplace lesson, exercise feedback, contextual tutoring, refresh recovery and deletion. The live systemd deployment then generated a different bakery/vegetarian-lunch lesson through HTTPS and continued teaching from its contents. Secure HttpOnly SameSite cookies, mobile layout, accessibility and deletion were checked. The original host's main website still returned HTTP 200.

The learner database was backed up with SQLite's online backup API and the backup passed `integrity_check`. The runtime uses `.next-preview` to separate the deployed build from `.next` development output, and runs as an enabled systemd service behind the existing HTTPS endpoint.

## Review improvements

Independent reviews found and corrected an AI output-schema mismatch, a paid-inference commit race, wrong-objective sequencing, oversized Unicode context, irrelevant source retrieval, a disappearing draft during delayed replies, expired-session recovery, stale exports across tabs, and deleted records lingering after bootstrap failure. Mobile conversation layout was revised so composing remains usable in long conversations and reduced-height viewports.

The release does not claim a validated proficiency assessment, account recovery, server-side speech recognition/TTS, or an award from an external design jury. These boundaries are visible in the product and roadmap. The optional live API checks remain ready for a configured credential.
